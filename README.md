# Hospitality Analysis Dashboard

## Overview
Developed an interactive Power BI dashboard to analyze hospitality industry performance and business metrics. The dashboard provides insights into revenue, occupancy rates, booking trends, and customer behavior.

## Tools Used
- Power BI
- Excel
- Data Visualization

## Key Features
- Revenue Analysis
- Occupancy Rate Tracking
- Booking Trend Analysis
- Customer Insights
- Interactive Dashboards

## Business Impact
The dashboard helps stakeholders monitor hotel performance, identify trends, and make data-driven decisions to improve operational efficiency and revenue.
